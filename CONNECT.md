# Подключить свой компьютер к статистике Codex

Сайт: https://176.124.205.198.sslip.io/.
Отправитель читает счётчики из локальных журналов Codex, догружает собственные
сессии с **1 октября 2026, 00:00 по Москве** и продолжает отправку автоматически.
Переписка и результаты инструментов в статистику не передаются.

Нужны Python 3.11+, установленный Codex CLI с выполненным входом и **ключ приёма**
от владельца сайта. Пароль просмотра сайта и ключ приёма различаются.
Ключ вводится скрыто при установке; не записывайте его в команды или репозиторий.

## Самый короткий способ: дать задание своему агенту

Откройте этот репозиторий в локальном Codex и отправьте:

> Прочитай CONNECT.md и подключи этот компьютер к общей статистике Codex.
> Определи ОС, доступную команду Python 3.11+ и проверь вход Codex CLI.
> Сохрани существующие machine, collector_id и baseline_ms в конфигурации
> отправителя; для новой машины выбери уникальное имя, например NAME-DEVICE.
> Используй существующий ключ приёма из usage-sender/config.json или OTLP;
> если ключа нет, попроси ввести его скрыто в локальном терминале.
> Выполни install --auto-repair --backfill-since "2026-10-01T00:00:00+03:00"
> с endpoint https://176.124.205.198.sslip.io/v1/usage, затем once и doctor.
> Прочитай backfill-report.json, проверь очередь, дневную сверку и исключения.
> Для unknown_owner сначала установи происхождение журнала и получи моё
> подтверждение, что это собственная история этой машины. Только после этого
> подключай подтверждённые сессии через --adopt-session; перенесённые, чужие
> и неоднозначные журналы не переназначай. Исходные журналы не меняй.
> Повтори проверку восстановления и сообщи, что загружено, что исключено
> и почему. Не выводи ключи, переписку и сырые журналы. Сохрани автозапуск,
> не останавливай активные сессии Codex и другие приложения.

Агент запускается на вашем компьютере: сервер не имеет доступа к вашим файлам.

## Установка вручную

Скачайте репозиторий или клонируйте его:

```sh
git clone https://github.com/Nikkfh5/codex-usage.git
cd codex-usage
```

Для новой машины замените `NAME-DEVICE` своим уникальным именем.
На macOS/Linux:

```sh
python3 codex_usage.py install --machine NAME-DEVICE --endpoint https://176.124.205.198.sslip.io/v1/usage --auto-repair --backfill-since "2026-10-01T00:00:00+03:00"
python3 codex_usage.py once
python3 codex_usage.py doctor
```

На Windows выполните те же команды с `python` вместо `python3`.
Для уже подключённой машины сохраните её имя: повторите `install` без
`--machine` и `--endpoint`; остальные флаги оставьте.

Установка сохраняет отправитель в `~/.codex/usage-sender` и настраивает
автозапуск: launchd на macOS, скрытую задачу Windows, пользовательский systemd
на Linux. На Linux отправитель работает, пока доступен пользовательский manager;
для работы без входа администратор может настроить lingering.

## Как понять, что подключение закончено

В выводе `doctor` должны быть `pending_events=0`, `last_error=null`,
`backfill_pending=false`, `database_check=ok` и `auto_repair=true`.
На сайте должна появиться карточка машины со свежим отчётом и без расхождений.

Прочитайте `~/.codex/usage-sender/backfill-report.json`: отсутствие очереди
не доказывает загрузку исключённых сессий. У нового участника история без
прежней серверной записи может получить `unknown_owner`; её нужно подтвердить
и подключить явно. `file_missing` требует найти исходный журнал, а не удалить
его учёт. Все остальные исключения тоже должны иметь понятную причину.
Ранее подключённая история сохраняется; дата ограничивает новую догрузку.

## Автоматическое исправление

После трёх неудачных обходов отправитель запускает локальный `codex exec`.
Агент разбирает ошибку и проверяет результат; одинаковая неустранённая ошибка
не вызывает бесконечные платные попытки. Для ручного повтора после устранения
причины выполните `python3 ~/.codex/usage-sender/codex_usage.py repair`
(на Windows: `python "$env:USERPROFILE\.codex\usage-sender\codex_usage.py" repair`).
При `needs_login` выполните `codex login`, затем повторите `repair`.

Поиск новых тарифов и пересчёт выполняются на сервере автоматически.
Показанная стоимость — эквивалент API по сохранённым токенам.
Подробности и диагностика: [README.md](README.md) и [agent-guide.md](agent-guide.md).
