Как считается стоимость

Стоимость этих токенов по тарифам API на 6 сентября 2026. Это ориентир для сравнения расхода, а не списание подписки Codex.

Вход без чтения и записи кэша × тариф входа + чтение кэша × тариф кэша + запись кэша × тариф записи + весь выход × тариф выхода. Reasoning уже входит в выход.

Известные Fast и Flex учитываются. При неизвестной скорости используется Standard с явной пометкой. Если не хватает счётчиков или тарифа, показана только рассчитанная часть (≥).

Цены в таблице — Standard за 1 млн токенов. Для GPT-5.6/6 Fast стоит ×2; для GPT-5.5 — ×2,5. Длинный контекст свыше 272 тыс. входных токенов учитывается отдельно. Платные вызовы инструментов, региональные надбавки и налоги не включены.
